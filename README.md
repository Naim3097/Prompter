# Prompter

Web-based teleprompter for video script delivery. Auto-scroll, adjustable speed, keyboard shortcuts, line highlighting.

Open `index.html` in any browser.

## Controls
- `Space` — play / pause
- `↑` / `↓` — previous / next line
- `R` — reset to top
- `+` / `-` — adjust scroll speed
- Click any line to jump
